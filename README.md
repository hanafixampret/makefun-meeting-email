One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. A judge model reads entries in pairs and keeps the funnier line.

Entry: "The meeting's only action item was to email everyone a summary of the meeting that should have been an email."

Run with `node main.ts` — it writes the entry to `/output/entry.txt`.
